# CodeForge Database Studio

Open source Filament panel plugin for database overview, schema design, migration tracking, health monitoring, smart seeding, documentation export (Markdown, HTML, PDF), and code generation.

## Features

- Database overview dashboard
- Visual schema designer
- Migration history and batch operations
- Query performance and health metrics
- Smart seeding with templates
- Documentation export (Markdown, HTML, PDF)
- Code generators (models, migrations, factories, seeders, Filament resources)
