# Legacy asset workspace

This folder holds optional screenshot and banner tooling from earlier packaging work. It is **not** part of the published package.

The project is an MIT-licensed community package:

- **Source:** https://github.com/hardikkanajariya-in/codeforge
- **Install:** `composer require hkdevs/codeforge-database-studio`
- **Support:** GitHub Issues

For current documentation, use the repository README, in-app docs (`/codeforge/docs` when enabled), or [GitHub Pages](https://hardikkanajariya-in.github.io/codeforge/).
